# Pokémon Binder Tracker

A small, private-use tracker for Pokémon card binders. Works offline once opened, saves progress on your device, and needs no account.

- All 1025 Pokémon in Pokédex order, with type-coloured sleeves
- Live search, type filter, and a page-by-page binder view with tick boxes
- Variants per slot (one variant fills the slot)
- Progress bars by generation and a page-complete flourish
- Export and Import backup in Setup

Your data is stored in your browser on one device. Use Export now and then.

## Deploy on GitHub Pages

1. Create a new public repository.
2. Upload every file in this folder (index.html, manifest.webmanifest, sw.js, both icons, README.md).
3. Go to Settings, then Pages. Set the source to the main branch, root folder, and save.
4. After a minute your site is live at `https://YOURNAME.github.io/REPO/`.
